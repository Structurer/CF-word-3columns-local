# CF_word3 / 单词背诵助手（PRD & README）

## 1. 项目概述

CF_word3（离线）是一个面向中文学习者的浏览器端单词记忆辅助工具，目标是用直观的三栏界面帮助用户高效完成“认识 → 记忆 → 复盘”的单词学习闭环。

它不依赖后端服务，直接在浏览器中运行，支持：
- 上传单词词库文件（JSON）
- 上传已有学习进度压缩包（ZIP）
- 在记忆区中逐个复习单词
- 通过键盘快捷键或拖动/滑动操作，将单词分类到“已牢记”或“待巩固”
- 导出学习进度，支持后续继续学习

---

## 2. 仓库结构分析

当前仓库是一个轻量级前端静态项目，核心文件如下：

- [index.html](index.html)：页面结构，定义三栏布局与交互入口
- [app.js](app.js)：核心逻辑，负责数据加载、状态管理、卡片渲染、快捷键与导入导出
- [style-day.css](style-day.css)：浅色主题样式
- [style-night.css](style-night.css)：深色主题样式
- [jszip.min.js](jszip.min.js)：用于处理 ZIP 压缩包的第三方库

### 2.1 现有实现特点

- 纯前端实现，无需安装依赖
- 基于本地数组状态管理单词流转
- 支持 JSON 和 ZIP 两种数据来源
- 支持主题切换、释义隐藏、打乱顺序、进度下载
- 适合个人学习场景和轻量复习流程

## 3. 产品需求说明（PRD）

### 3.1 产品定位

“CF_word3”是一款面向英语/外语学习者的个人学习工具，重点解决以下问题：
- 单词学习过程缺乏结构化分类
- 复习时难以快速记录“已掌握/还需巩固”状态
- 传统记忆工具不适合简单、低门槛的本地使用场景

### 3.2 目标用户

- 需要系统复习单词的人
- 喜欢使用本地工具而非登录型平台的人
- 希望快速导入自己的词表并继续学习的人

### 3.3 产品目标

1. 提供一个轻量、直观、可离线使用的单词记忆界面
2. 让用户能够快速从词库文件开始学习，而不是先配置复杂环境
3. 支持“学习进度可保存、可恢复”的闭环体验
4. 让单词处理动作尽量简单，减少操作成本

### 3.4 非目标

- 不提供用户账号系统
- 不提供云端同步
- 不提供复杂的记忆算法（如间隔重复调度）
- 不提供多人协作或共享词库功能

## 4. 核心功能需求

### 4.1 词库导入

支持两种文件类型：

1. 单词 JSON 文件
   - 文件格式应为数组
   - 每个元素至少包含以下字段：
     - word：单词
     - translations：释义数组或对象

2. 学习进度 ZIP 包
   - 压缩包内需要包含三个文件：
     - 记忆区.json
     - 已牢记.json
     - 待巩固.json

### 4.2 三栏学习流程

界面分为三列：
- 左列：已牢记
- 中间列：记忆区
- 右列：待巩固

用户可以通过以下方式改变单词所在列：
- 键盘快捷键
  - 左箭头 / 空格：移至已牢记
  - 右箭头：移至待巩固
  - 上下箭头：切换当前单词
  - Enter：提交输入内容
- 鼠标操作
  - 在卡片上进行滑动操作
  - 双击侧栏单词可重新移回记忆区

### 4.3 单词复习体验

- 中间栏显示当前正在复习的单词
- 用户可输入当前单词进行验证
- 输入正确时，单词自动进入“待巩固”
- 输入错误时，给出提示并高亮输入框
- 支持隐藏/显示释义，便于更真实地测试记忆
- 支持打乱记忆区顺序，增加复习多样性

### 4.4 进度保存与导出

- 学习过程中，当前状态保存在内存中
- 用户可下载 ZIP 包，包含三份 JSON 文件，便于下次继续学习
- 下载文件名会根据词汇表名称与时间戳生成

### 4.5 主题与界面

- 支持浅色/深色主题切换
- 顶部提供快捷键提示、操作反馈和词汇表名称显示
- 支持双击编辑词汇表名称

## 5. 用户流程

### 5.1 首次使用

1. 打开网页
2. 上传单词 JSON 文件
3. 开始在中间栏复习单词
4. 使用快捷键或滑动操作完成分类
5. 需要时下载进度包

### 5.2 继续学习

1. 重新上传之前下载的 ZIP 包
2. 读取已有三栏状态
3. 从上次中断位置继续复习

## 6. 数据结构说明

### 6.1 单词对象示例

```json
[
  {
    "word": "apple",
    "translations": [
      { "translation": "苹果；苹果树", "type": "n." }
    ]
  }
]
```

### 6.2 进度包内容

压缩包内应包含：
- 记忆区.json
- 已牢记.json
- 待巩固.json

每个文件都应为一个数组，内容为单词对象。

## 7. 技术实现说明

### 7.1 技术栈

- HTML：页面结构
- CSS：主题与布局样式
- JavaScript：交互逻辑与状态管理
- JSZip：ZIP 压缩包导入/导出

### 7.2 架构特点

- 采用单页静态页面结构
- 状态以全局变量形式维护
- DOM 由 JavaScript 动态渲染
- 无框架依赖，适合快速迭代和轻量部署

### 7.3 运行方式

直接在浏览器中打开 [index.html](index.html) 即可使用。

> 无需构建工具、无须安装依赖，适合本地学习和快速演示。

## 9. 当前限制与后续优化方向

### 9.1 当前限制

- 目前没有后端，无法实现云端同步
- 没有引入间隔重复算法，学习安排较简单
- 数据结构依赖前端约定格式，需用户按规范提供 JSON
- 进度仅保存在本地文件，不支持跨设备同步

### 9.2 后续可优化方向

- 接入后端，实现用户账户与云端同步
- 引入间隔重复（Spaced Repetition）算法，提高复习效率
- 支持更多词库格式（如 CSV、Anki 词库）
- 增加统计分析，如掌握率、复习时长、遗忘趋势
- 增加移动端适配与手势优化
